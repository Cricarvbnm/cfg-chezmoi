# dot_config

Configuration for various applications and system components.

## Features

### git

Git client configuration:

- User name and email
- Custom aliases (`a`, `aa`, `s`, `sl`, `c`, `ca`, `cu`)
- [Delta](https://github.com/dandavison/delta) as diff pager
- Default branch name

### kitty

Terminal emulator with Catppuccin-Macchiato theme.

### kglobalshortcutsrc

KDE Plasma global shortcuts for:

- Window management (**Krohnkite tiling**, ...)
- Volume and microphone control
- Keyboard layout switching
- Session management (lock, logout, reboot, shutdown)

This file is tracked because of krohnkite.

### nvim

External: LazyVim Neovim configuration.

Synced from [My LazyVim Configuration](ssh://git@codeberg.org/Alechron/cfg-lazyvim.git)
