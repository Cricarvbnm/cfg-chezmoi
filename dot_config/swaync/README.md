# SwayNC — ~/.config/swaync/

Notification daemon for Wayland with Catppuccin Macchiato themed CSS.

## Configuration

**Files**: `config.json` + `style.css`

- Minimal config (fit-to-screen off)
- Full Catppuccin Macchiato CSS styling
- `Mod+N` toggles notification panel
- `Mod+Shift+N` dismisses all
