# Fontconfig — ~/.config/fontconfig/

System font preferences for CJK compatibility.

## Configuration

**File**: `fonts.conf`

| Category | Preferred Font |
|---|---|
| Serif | Noto Serif CJK SC |
| Sans-serif | Noto Sans CJK SC |
| Monospace | Fantasque Sans Mono, fallback FantasqueSansM Nerd Font |
