# Fcitx5 — ~/.config/fcitx5/

Input method framework with [Rime](https://rime.im/) engine. Restrictive permissions via `private_` prefix.

## Configuration

**Files**: `private_config` + `private_profile`

## External Dependencies

The Rime data directory (`~/.local/share/fcitx5/rime`) is managed externally via `.chezmoiexternal.toml`:

| Source | Type | Description |
|--------|------|-------------|
| [rime-ice](https://github.com/iDvel/rime-ice) | archive | Rime input schema collection |
| [moegirl.dict.yaml](https://github.com/outloudvi/mw2fcitx) | file | Moegirl wiki dictionary |
