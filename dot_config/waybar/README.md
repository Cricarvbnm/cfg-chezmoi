# waybar — ~/.config/waybar/

Top bar for hyprland with Catppuccin Macchiato theme.

## Configuration

**Files**: `config.jsonc` + `style.css`

### Modules

- hyprland workspace switcher (kanji icons: 一二三…)
- Clock with calendar tooltip
- System tray, privacy indicator, idle inhibitor
- Network (Wi-Fi/Ethernet via NM)
- PulseAudio (volume + mute, right-click opens pwvucontrol)
- Backlight (scroll to adjust)
- CPU temperature, CPU usage, memory usage (click to open btop)
- Power profiles (power-saver/balanced/performance, click to cycle)
- UPower devices (bluetooth batteries)
- Battery (internal, with charging state and time estimate)
