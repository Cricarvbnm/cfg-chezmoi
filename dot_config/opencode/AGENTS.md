# AGENTS.md

## 知识库

共享 Obsidian vault 位于 `~/knowledge/`，是封装了知识的可复用文档库，供 agent 和人类共同查阅。

- 规划任务时先检索知识库
- 知识库的目录约定、使用方式、实践记录路径等由 `~/knowledge/AGENTS.md` 定义，需要时查阅
- 发现值得保留的优秀实践时，记录到知识库（人类可从中发掘可保存为文档的知识）
- 不提交 secret 到知识库

## 环境信息

机器特定的环境事实（OS、可用工具、包管理器 等）记录在 `~/.config/opencode/env.md`。

- agent 按需读取和更新
- 只记录机器级信息，不包含项目级约定

## 语言与格式

- 默认使用简体中文
- 代码和文档中的注释优先使用英文

## 图表

需要图示时，首选 Mermaid，优于 ASCII 字符画。目录结构仍可用字符画表示。

## 权限边界

不主动使用 sudo 等提权方法。如需提权，给出方法和理由，让用户代为操作。
