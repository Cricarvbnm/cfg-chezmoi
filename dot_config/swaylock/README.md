# swaylock — ~/.config/swaylock/

Screen locker with Catppuccin Macchiato theme.

## Configuration

**File**: `config`

- Catppuccin Macchiato colors
- Clock display (`%H:%M` + `%Y-%m-%d`)
- Blur effect (7x5), vignette
- Indicator ring with radius 160, thickness 8

Triggered by `swayidle` after 5 minutes of inactivity. Also manually via `Super+Alt+L`.
